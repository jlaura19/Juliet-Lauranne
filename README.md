# Juliet's Portfolio

A responsive personal portfolio for showcasing software engineering interests, projects, skills, and learning milestones. It is built with React and Vite and uses a dark, terminal-inspired visual style.


## External services and privacy

- The projects section requests public repository data from GitHub in the visitor's browser. It needs an internet connection; GitHub may apply anonymous API rate limits. No GitHub token is required by this app.
- Submitting either contact form opens a prefilled email draft in the visitor's default email app. The visitor reviews and sends it themselves.
- No API keys or other secrets are needed for local development or building. Keep credentials and private configuration out of source control; `.env` files are ignored by Git.
